# 🏃 Execution Guide

Complete reference for running tests in every mode and environment.

---

## Basic Execution

```bash
# Activate virtual environment first!
# Windows:
.venv\Scripts\activate
# Linux/Mac:
source .venv/bin/activate

# Run all smoke tests
pytest tests/ -m smoke -v

# Run all regression tests
pytest tests/ -m regression -v

# Run everything
pytest tests/ -v
```

```bash
# ── UI Tests ─────────────────────────────────────────────────
pytest tests/ -m ui -v

pytest tests/ -m dashboard -v
pytest tests/ -m ecommerce -v
pytest tests/ -m rbac -v

# ── API Tests ────────────────────────────────────────────────
pytest tests/ -m api -v
pytest tests/ -m crud -v
pytest tests/ -m auth -v

# ── Database Tests ───────────────────────────────────────────
pytest tests/ -m database -v

# ── Priority ─────────────────────────────────────────────────
pytest tests/ -m smoke -v          # Quick sanity (run first)
pytest tests/ -m regression -v     # Full suite
pytest tests/ -m "smoke and login" # Specific subset

# ── Positive/Negative ────────────────────────────────────────
pytest tests/ -m positive -v
pytest tests/ -m negative -v
pytest tests/ -m security -v
```

## By Test File / Folder

```bash
# Entire folder
pytest tests/ui/ -v
pytest tests/api/ -v
pytest tests/database/ -v

# Specific file
pytest tests/ui/test_login.py -v
pytest tests/api/test_crud_api.py -v

# Specific test class
pytest tests/ui/test_login.py::TestLogin -v

# Specific test method
pytest tests/ui/test_login.py::TestLogin::test_valid_login -v
```

## Browser Selection

```bash
# Default (from .env or config)
pytest tests/ -v

# Chrome (explicit)
pytest tests/ --browser=chrome -v

# Firefox
pytest tests/ --browser=firefox -v

# Edge
pytest tests/ --browser=edge -v

# Headless mode (no visible browser)
pytest tests/ --headless=true -v

# Headless Firefox
pytest tests/ --browser=firefox --headless=true -v
```

## Parallel Execution

> **Windows note:** Use `-n 2` or `-n 4`. Avoid `-n auto` on OneDrive-synced paths.

```bash
# 2 parallel workers (safe for most machines)
pytest tests/ -n 2 -v

# 4 parallel workers
pytest tests/ -n 4 -v

# Auto-detect CPU cores (Linux/Mac recommended)
pytest tests/ -n auto -v

# Parallel + specific suite
pytest tests/ui/ -m regression -n 4 -v

# Parallel + headless (ideal for CI)
pytest tests/ -n 4 --headless=true -v
```

---

## Retry Failed Tests

```bash
# Retry each failure up to 2 times with 3s delay
pytest tests/ --reruns=2 --reruns-delay=3 -v

# Retry 3 times
pytest tests/ --reruns=3 --reruns-delay=5 -v
```

## Environment Targeting

```bash
# Dev environment (default)
pytest tests/ --env=dev -v

# Staging environment
pytest tests/ --env=staging -v

# Override via environment variable
set ENVIRONMENT=staging && pytest tests/ -v       # Windows
ENVIRONMENT=staging pytest tests/ -v              # Linux/Mac
```

## Reporting

```bash
# HTML report (auto-generated by default via pytest.ini)
pytest tests/ -v
# Opens: reports/html-reports/report.html

# Custom HTML report name
pytest tests/ --html=reports/html-reports/my_run.html --self-contained-html

# Allure report data collection
pytest tests/ --alluredir=reports/allure-results

# Open Allure report (live server)
allure serve reports/allure-results

# Generate static Allure HTML
allure generate reports/allure-results -o reports/allure-report --clean
# Opens: reports/allure-report/index.html
```

## Docker Execution

```bash
# Build Docker image
docker build -t ai-test-framework -f docker/Dockerfile .

# Run smoke tests in container
docker run --rm ai-test-framework pytest tests/ -m smoke -v

# Run regression headless
docker run --rm \
  -e HEADLESS=true \
  -e BROWSER=chrome \
  -v $(pwd)/reports:/app/reports \
  ai-test-framework \
  pytest tests/ -m regression -v

# Full stack: Selenium Grid + MySQL
cd docker
docker-compose up -d
docker-compose run test-runner pytest tests/ -m regression -v
docker-compose down -v
```

## Advanced Options

```bash
# Stop on first failure
pytest tests/ -x -v

# Stop after N failures
pytest tests/ --maxfail=3 -v

# Show 10 slowest tests
pytest tests/ --durations=10 -v

# Verbose output with no capture
pytest tests/ -v -s

# Generate full test list (no execution)
pytest tests/ --collect-only

# Run last failed tests
pytest tests/ --lf -v

# Run failed first, then rest
pytest tests/ --ff -v

# Filter by keyword in test name
pytest tests/ -k "login" -v
pytest tests/ -k "login and not security" -v
pytest tests/ -k "test_valid" -v

# Disable AI modules for speed
AI_ENABLED=false pytest tests/ -v

# Run with Cloud AI enabled (requires GEMINI_API_KEY in .env)
AI_ENABLED=true USE_MOCK_AI=false pytest tests/ -v

# Run with local rule-based/mock fallback engines (guarantees no cloud quota errors)
AI_ENABLED=true USE_MOCK_AI=true pytest tests/ -v

# Debug mode (show all print statements)
pytest tests/ -s --log-cli-level=DEBUG -v
```

  -m regression \
  -n 4 \
  --headless=true \
  --tb=short \
  --reruns=2 \

  --html=reports/html-reports/ci_report.html \

  --alluredir=reports/allure-results \
